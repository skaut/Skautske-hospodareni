Aplikace je napsaná v PHP 8.5+ (Nette, Doctrine) a běží na hostingu h.skauting.cz: PHP-FPM za webovým serverem Apache 2.4 na Debianu 13 a databáze MySQL 8.4. Vývojové i testovací prostředí v Dockeru tomu odpovídá.

Pro zapojení do vývoje si přečtěte [dokumentaci projektu](.docs/README.md), zejména [plánování práce](.docs/planovani-prace.md).
