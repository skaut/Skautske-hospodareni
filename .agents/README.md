# Agent instructions

This directory contains working instructions for Codex and other automated agents, not user documentation.

- Read `repository.md` for mandatory repository, architecture, Docker, test, and quality rules.
- Read `ui-ux-guideline.md` for every user-facing route change.
- Read `upgrade-plan.md` only when working on the Nette 4 upgrade.
- Consult `acceptance-false-failures.md` when diagnosing a CI acceptance-test failure.

Write agent-facing prose in concise English. Preserve Czech only for literal UI text, routes, and Czech Scout domain terms. The root `AGENTS.md` is a short discovery entry point for tools that locate instructions automatically.
